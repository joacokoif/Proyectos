## 🗂️ Proyectos

| Proyecto | Descripción | Stack |
|---|---|---|
| [⚽ fpl](./fpl) | Predictor de Fantasy Premier League con ML + optimización MILP | Python · LightGBM · PuLP |

| [📈 stocks](./stocks) | Screener cuantitativo de Mega Caps + estrategia BTC MACD-ATR | Python · yfinance · Binance API |
| [🌌 Galaxy Classifier](./Galaxy%20Classifier) | Clasificador de morfología galáctica con Transfer Learning (ResNet18 / EfficientNet) | Python · PyTorch · scikit-learn |
| [⚔️ Football Match Detector](./Football%20Match%20Detector) | Detector de enfrentamientos David vs Goliat en ligas de fútbol europeo | Python · Rich · football-data.org |
| [🎵 Spotify Lyrics Widget](./Spotify%20Lyrics%20Widget) | Widget de escritorio flotante con letras sincronizadas de Spotify | Python · Tkinter · winsdk |
